# Project Context

Project name: **AI Health and Wellness App Project**

## Purpose

Build a modern, professional website and lightweight app experience for AI Health & Wellness Hub. The site promotes AI-powered wellness content and captures subscribers with a free 7-day AI meal plan.

## Current State

The current project is a static site with:

- Landing/home hero.
- AI Nutrition, Fitness, Mental Wellness, and Sleep sections.
- Original article library with Amazon affiliate links.
- Tool comparison section.
- 7-day AI Health Kickstart Challenge.
- Preserved 7-day meal plan displayed by meal type.
- Interactive 7-day meal generator based on user weight, goal, and diet preference.
- Subscribe form connected for Netlify deployment.
- Legal/disclaimer/footer links.
- SEO metadata, canonical URL, Open Graph metadata, `robots.txt`, and `sitemap.xml`.

## Visual Direction

- Dark navy background.
- Dark green and blue button gradients.
- Custom AI Health logo in the header.
- p5.js floating glass-bubble animation on the first page.
- Professional typography and spacing.
- Avoid purple/violet button gradients.
- Keep the site polished, trustworthy, health-tech, and not cartoonish.

## Important User Preferences

- Preserve original content and article links.
- Preserve Amazon affiliate links.
- Keep the logo in the top-left header but keep the existing site name and tagline text.
- Buttons should use darker green and blue gradients.
- First-page background should use floating bubbles, not waves.
- Spacing must look professional, with no large awkward vertical gaps.
- The meal generator should stay incorporated into the site.

## Deployment Preference

Netlify is the preferred future deployment target for the modern static site.

## Local Preview

Use:

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

Open:

```text
http://127.0.0.1:5173/index.html
```

If the server stops, restart it with the same command.
